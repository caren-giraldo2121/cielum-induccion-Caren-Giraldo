## Cielum Inducción - Caren Giraldo

Repositorio creado para recopilar y documentar las actividades realizadas durante el proceso de inducción técnica en Cielum, incluyendo ejercicios de desarrollo y prácticas relacionadas con el uso de Git y GitHub.

## Descripción

Este repositorio contiene las actividades, ejercicios y prácticas realizadas durante el proceso de inducción en Cielum, orientadas al fortalecimiento de conocimientos en desarrollo de software, Git y GitHub.

## Objetivos
- Practicar el uso de Git y GitHub.
- Aplicar diferentes estrategias de control de versiones.
- Comprender el manejo de ramas y commits.
- Fortalecer buenas prácticas para el trabajo colaborativo.
- Registrar el progreso de las actividades realizadas durante la inducción.
